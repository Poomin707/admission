# Smart College Admission Web Application (All-in-One)
> ระบบรับสมัครเรียนและรายงานตัวออนไลน์แบบครบวงจร (ปวช./ปวส.) หน้าเดียวจบ (Single-File Web App)

ระบบรับสมัครนักเรียน นักศึกษาใหม่ออนไลน์ที่รวมทั้งฝั่งผู้สมัคร (Front-end Portal) และฝั่งเจ้าหน้าที่ (Back-end Dashboard) ไว้ในระบบเดียว ดีไซน์ทันสมัย สะอาดตาสไตล์ Modern Bento Grid โทนสี Deep Navy Blue & Cyan/Mint ใช้งานได้ทั้งบนโทรศัพท์มือถือและเดสก์ท็อปอย่างสมบูรณ์แบบ

---

## ✨ ฟังก์ชันและคุณสมบัติเด่น (Features)

### 🌐 ฝั่งผู้สมัครเรียน (Applicant Portal)
1. **Landing Page & Admission Timeline:**
   - แบนเนอร์ดีไซน์ Glassmorphism พร้อมไทม์ไลน์ 4 ขั้นตอนการรับสมัคร
2. **Smart Form & Validation:**
   - Multi-step Stepper Form แบ่ง 4 ขั้นตอนชัดเจน
   - ตรวจสอบความถูกต้องของเลขประจำตัวประชาชน 13 หลักด้วยสูตร Modulo 11 ตามมาตรฐานกรมการปกครอง
   - จัดรูปแบบเบอร์โทรศัพท์ 10 หลักอัตโนมัติ
   - คัดเลือกระดับชั้น (ปวช. / ปวส.) และสาขาวิชา (IT, ช่างยนต์ EV, ไฟฟ้ากำลัง, บัญชี, การตลาด, เมคคาทรอนิกส์)
3. **Document Upload System:**
   - ระบบอัปโหลดเอกสาร Drag & Drop (รูปถ่าย 1.5", สำเนาบัตร ปชช., ทะเบียนบ้าน, ปพ.1/รบ.1) พร้อม Live Preview ขนาดไฟล์
4. **Status Tracking:**
   - ค้นหาสถานะด้วยเลขบัตรประชาชน 13 หลัก แสดงการ์ดสถานะ (🟢 ผ่านการคัดเลือก, 🟡 รอตรวจสอบ, 🔴 เอกสารไม่ครบ, 🎓 มอบตัวแล้ว)
5. **Auto-Generate PDF Download:**
   - แบบฟอร์มพิมพ์ใบสมัครและใบมอบตัวขนาด A4 มาตรฐานราชการ พร้อมบาร์โค้ดประจำตัวและช่องลงนาม (สั่งพิมพ์หรือบันทึก PDF ผ่านเบราว์เซอร์ได้ทันที)

---

### 🔒 ฝั่งเจ้าหน้าที่และงานทะเบียน (Admin Dashboard)
1. **Bento Grid Analytics:**
   - แดชบอร์ดสรุปยอดผู้สมัครรวม, ผ่านการคัดเลือก, รอตรวจเอกสาร
   - กราฟแท่งแสดงสถิติยอดผู้สมัครแยกตามแผนกวิชา เปรียบเทียบกับโควตาที่เปิดรับ
   - อันดับโรงเรียนเดิมและสัดส่วนผู้สมัครในเขต/นอกเขต
2. **Advanced Data Table & Slide-Out Drawer:**
   - ตารางค้นหาและกรองผู้สมัครตามระดับชั้นและสถานะ
   - คลิกเพื่อเปิดลิ้นชักด้านข้าง (Drawer Panel) ตรวจแฟ้มเอกสารแนบโดยไม่ต้องสลับหน้า
   - ปุ่มเปลี่ยนสถานะด่วน (Quick Status Changer) ในคลิกเดียว
3. **Auto Student ID Generator:**
   - ระบบคำนวณและออกรหัสนักศึกษาให้อัตโนมัติ (เช่น `68209010042`) เมื่อกดมอบตัวสำเร็จ
4. **Registry Excel Export (แบบ ศธ.02):**
   - ส่งออกข้อมูลเป็นไฟล์ Excel/CSV (UTF-8 BOM รองรับภาษาไทย 100%) ตามรูปแบบมาตรฐานงานทะเบียน
5. **Notification Simulation:**
   - จำลองระบบส่งการแจ้งเตือนผลผ่าน LINE OA / LINE Notify

## 🚀 วิธีการเปิดใช้งาน (Getting Started)

ระบบนี้ถูกพัฒนาในรูปแบบ **Zero-Dependency Single-File Web App**:
1. Clone หรือ Download Repository นี้ลงเครื่อง
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Google Chrome, Microsoft Edge, Safari, Firefox)
3. สามารถใช้งานได้ทันทีโดยไม่ต้องติดตั้ง Node.js หรือ Web Server ใดๆ

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5 & Vanilla JavaScript (ES6+):** การจัดการ State และ Event-driven UI
- **Tailwind CSS (CDN):** Modern Responsive Styling & Dark/Navy Theme
- **Web Storage API (localStorage):** ซิงค์ข้อมูลผู้สมัครกับแดชบอร์ดแบบ Real-time
- **Print CSS (`@media print`):** ฟอร์แมตเอกสาร A4 คุณภาพสูงสำหรับการพิมพ์หรือบันทึก PDF
